# 011 · AQRAB

**Category:** Automotive  
**Concept:** A fictional next-generation military mobility vehicle from the year 2100, shown as a cinematic 3D website: a night-street reveal controlled by scroll, an explorable command-centre interior and a defence-technology brand story. Replaces the earlier hypercar concept; do not use the green hypercar images.  
**Website:** /showcase/aqrab/  
**Images:** 18 generations, 30 images  
**Image status:** New concept (26 Nov): generate these; the old green hypercar set is not used

## Visual direction

- **Look:** cinematic science-fiction film still, anamorphic 35mm look, deep true blacks, restrained practical lighting, cool haze, thin cyan-green accent light.
- **Palette:** void black, gunmetal, cold sodium amber, ultraviolet cyan-green.
- **Consistency:** every prompt below ends with the same look and palette sentence, so the set matches. Generate the hero first; if it lands, keep the others as written. Grids (2x2) give four images from one generation; Claude cuts them into four files.
- **People:** any shot with people asks for clearly different individuals, because Seedream repeats one face when people are not described apart. Never add a real person or a brand.

## Settings (Higgsfield website)

Seedream 5.0 Pro · Quality 2K · Count 1/4 (keep it at 1/4 so Unlimited stays on) · Aspect ratio as listed · No reference images.
