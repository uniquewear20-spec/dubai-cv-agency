A-300PrinciplesThree rules on every drawing board

Start with the climate, not the shape.

  1. Rule 01

    Begin with the sun.

    Orientation is the cheapest decision on any project, and the hardest one to undo. We settle it before we draw a single wall.

  2. Rule 02

    Shade is a material.

    A deep roof, a screen, a row of trees. In a hot city, shade is what people actually feel, so we design it as carefully as stone.

  3. Rule 03

    Build less, and keep it.

    The lowest-carbon building is usually the one already standing. We repair, extend and reuse before we replace.
